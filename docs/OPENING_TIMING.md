# 通用开局时点参考与偏差排查

更新：2026-10-15。相同开局、相同规则版本、没有实际敌方干扰时，各地图前期经济时点应接近。路线差异不应成为所有建造延误的默认解释。这里只用于监测，不要求机器人等固定秒数才建造。

同版本同出生点追加观察：011602与012041的16经济节点相对005630最大偏差分别2.550／5.280秒，未触发时点阈值；第四塔失败不在这16个有效节点中，仍须独立处理。两局非自然终局，不提升基准为已验收；0.1.132版本变化须标注，不覆盖原候选。

## 每局执行

review_map_pool.py会自动生成本局opening-timing-review.json及.md，分别保存：建造尝试、地基出现、已确认完工阶段、英雄／科技观察和实际敌方接触。失败重试与真实建筑采用独立编号，不能把重试次数当成已建塔数。

初始提醒门槛为max(20游戏秒,参考时点15%)。超出门槛或地基未确认时，优先查：

1. 有无实际敌方攻击、回防、工人／建筑损失；是否只有野怪交战。
2. 当时金币、木材、人口和已付费生产队列，是否有补兵或购物抢占预算。
3. 工人采金、采木、空闲、施工预留与回矿时间。
4. 下单到地基的间隔、落点失败、路径／通道与home_layout_timing耗时。
5. 版本、出生点、采样粒度等差异；把实际原因与尚未证实的推断分开。

参考未校准或版本不同也保存差异，但不自动判合格／失败。基准只能依据复盘证据更新，不用新对局反过来覆盖旧证据；003530保留为异常对照。具体练级路线仍按MAP_STRATEGIES中的当前地图章节执行。
