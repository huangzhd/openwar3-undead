2. **中期双英雄蓝量**：巫妖出来后，练级时保留DK和巫妖的蓝量，不要过分在野怪身上消耗蓝量，为三本一波保蓝。满蓝时允许一次技能利用自然回蓝，之后尽量保留；实际耗蓝后回满才重新允许一次，不能在同一满蓝快照连续施法；只有常驻部队急需保命（残血可消耗骷髅不触发额外耗蓝），或现有输出不足以练下野怪时才例外。保蓝不能阻止必要的救命施法，也不能解释为完全禁用技能。
3. **进攻节奏**：三英雄＋腐球就进攻，不等6蜘蛛；2026-10-17 CH路线例外：商店后西侧狗头或下方鱼人、近家实验室，再在三本巫妖持球且DK归队后练中央分矿，清完衔接进攻；保留安全判断和明确记录的有界跳过；持续补兵并会合。首攻卖掉TP；DK蓝充足优先腐球和第三英雄，蓝瓶按需且不作为出征门槛（0.1.137暂用150蓝/两次缠绕为充足阈值），缺蓝时也不抢核心采购预算或专程拖主队回家；覆盖旧“必须买蓝瓶”及“首攻允许TP”；当前方案不使用或补购TP。备战须及时完成，受阻记录原因，不无限等待。
4. **侦察**：避野、减少折返；确认敌方出生点后留在前方，允许阵亡，不保命返家、不补派。
5. **基地与装备**：二本完成先付三本，再付巫妖，之后屠宰场与新通灵塔；只有招巫妖必需人口可先补，真实紧急防守/复活优先。基地建筑留通道；前期DK初购骷髅棒之外只补购一次；二本巫妖登场后由巫妖买一组骷髅棒，以背包确认后追随DK和主队会合练级，不再派DK回家二本补棒。采购者独立行动，不把整队拖回商店；保留危险、路径、库存和超时限制。DK买到腐球后交给巫妖，随后按C3路线进攻。买球/送球途中遇敌时，巫妖带主队先安全后撤，DK与撤退中的主队会合；以巫妖背包确认腐球后再恢复交战。交接受阻/超时应脱险撤退，不让主队提前硬打；基地回防和紧急保命仍优先。保留幻象权杖，三本一波接敌时对真实DK制造最多三个幻象，前置扛伤；幻象不能计作真实英雄或参与DK保命判定。
6. **团战与雕像**：蜘蛛扇形展开、不聚团，给DK留撤离通道；雕像贴近主队或伤员，手动交替释放回血与回蓝；两辆同时在队时保留自动补给兜底并手动补另一资源。只有一辆在前线（包括另一辆变毁灭、替补仍远）时自动回血、手动回蓝，优先伤员但不长期断蓝；真实威胁才后拉。
7. **拆家优先级**：优先可见、可达的农民和在建建筑；对暗夜按“正在攻击我方的大树 → 正在生产中的大树 → 月井 → 其他”处理。第二项沿用用户最新原文，不能用旧版“在建大树”代替；生产状态只依据接口允许的可见证据，未知时不得推断。

8. **毁灭驱散与编成**：三本完成且两辆雕像实际造出后，再在屠宰场研究毁灭；生产队列不算实际出场。看到己方英雄可驱散debuff、敌方召唤物或敌方可驱散buff，即可选择能接近最高优先目标的低蓝可行动雕像变身一只毁灭；按英雄debuff→敌方召唤物→敌方buff优先驱散，同级优先覆盖更多目标。练级/防守同样适用；紧急撤退不新变身，已有未后拉毁灭可就近为英雄解控，不追逐视野外目标。50人口阶段编成为3英雄、4蜘蛛、1毁灭、2雕像，加5侍僧/3食尸鬼实际49人口；尚无上述可驱散目标时先备3雕像并留2人口，不盲变身。变身后补足两雕像；前线暂时只剩一辆时自动回血、手动回蓝，不能因基地已有替补就关闭前线回血。第三蜘蛛在三本、巫妖付款后才招；第五通灵塔等第三英雄实际出场。历史后期存钱突破维护费逻辑保留。

## 每次复盘先检查核心策略

每条结论只能标记“符合／违反／未触发／证据不足”。同一条有多项行为时分别记录，不用部分通过代表整条通过；违反项保留时间、实际行为、相关条件和下一步。缺少事件或命令回执成功不能证明符合。例外用蓝必须说明当时保命需求或输出不足证据；未知则标记证据不足。

## 通用开局时间检查（2026-10-15新增）
