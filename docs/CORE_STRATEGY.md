## 八条核心策略

1. **练野与DK保命**：无玩家实际干扰，绝不练野TP。DK约半血后拉、转移仇恨，脱险后再输出，尽量一次清完营地。前期DK招出第一组骷髅就开始练级，保持连贯的练级节奏。
2. **中期双英雄蓝量**：巫妖出来后，练级时保留DK和巫妖的蓝量，不要过分在野怪身上消耗蓝量，为三本一波保蓝。满蓝时允许一次技能利用自然回蓝，之后尽量保留；实际耗蓝后回满才重新允许一次，不能在同一满蓝快照连续施法；只有常驻部队急需保命（残血可消耗骷髅不触发额外耗蓝），或现有输出不足以练下野怪时才例外。保蓝不能阻止必要的救命施法，也不能解释为完全禁用技能。
3. **进攻节奏**：三英雄＋腐球就进攻，不等6蜘蛛；2026-10-16用户新增CH例外：持球且DK归队后先练中央分矿，清完衔接进攻，保留安全判断并有界等待；持续补兵并会合。首攻卖掉TP；DK蓝充足优先腐球和第三英雄，蓝瓶按需且不作为出征门槛（0.1.137暂用150蓝/两次缠绕为充足阈值），缺蓝时也不抢核心采购预算或专程拖主队回家；覆盖旧“必须买蓝瓶”及“首攻允许TP”；当前方案不使用或补购TP。备战须及时完成，受阻记录原因，不无限等待。
4. **侦察**：避野、减少折返；确认敌方出生点后留在前方，允许阵亡，不保命返家、不补派。
5. **基地与装备**：二本完成先付三本，再付巫妖，之后屠宰场与新通灵塔；只有招巫妖必需人口可先补，真实紧急防守/复活优先。基地建筑留通道；二本巫妖登场后，缺骷髅棒由DK独立采购，巫妖带主队继续练级，DK实际买到后追随主队归队。DK买到腐球后交给巫妖，随后按C3路线进攻。买球/送球途中遇敌时，巫妖带主队先安全后撤，DK与撤退中的主队会合；以巫妖背包确认腐球后再恢复交战。交接受阻/超时应脱险撤退，不让主队提前硬打；基地回防和紧急保命仍优先。保留幻象权杖，三本一波接敌时对真实DK制造最多三个幻象，前置扛伤；幻象不能计作真实英雄或参与DK保命判定。
6. **团战与雕像**：蜘蛛扇形展开、不聚团，给DK留撤离通道；两雕像固定一回血、一回蓝，贴近主队或伤员，只有真实威胁才后拉。
7. **拆家优先级**：优先可见、可达的农民和在建建筑；对暗夜按“正在攻击我方的大树 → 正在生产中的大树 → 月井 → 其他”处理。第二项沿用用户最新原文，不能用旧版“在建大树”代替；生产状态只依据接口允许的可见证据，未知时不得推断。

8. **毁灭驱散与编成**：三本完成后在屠宰场研究毁灭。进攻看到当前可见敌方召唤物，优先选择可行动的低蓝雕像变身一只毁灭，并优先在射程内对召唤物密集处使用吞噬魔法；紧急撤退优先，不追逐视野外目标。50人口阶段编成为3英雄、4蜘蛛、1毁灭、2雕像，加5侍僧/3食尸鬼实际49人口；没遇召唤物先备3雕像并留2人口，不盲变身。变身后维持两雕像一回血一回蓝。第三蜘蛛在三本、巫妖付款后才招；第五通灵塔等第三英雄实际出场。历史后期存钱突破维护费逻辑保留。

## 每次复盘先检查核心策略

源码与终局分类核验后，先逐条检查下表，再分析当前地图路线和其他优化项。沿用地图／战斗／装备／DK四复盘，并在本局证据目录保存 `core-strategy-review.md`，引用四复盘及原始事件；该清单是人工审查要求，不表示现有脚本已经自动生成或判定。

每条结论只能标记“符合／违反／未触发／证据不足”。同一条有多项行为时分别记录，不用部分通过代表整条通过；违反项保留时间、实际行为、相关条件和下一步。缺少事件或命令回执成功不能证明符合。例外用蓝必须说明当时保命需求或输出不足证据；未知则标记证据不足。

## 通用开局时间检查（2026-10-15新增）

同一开局版本在没有实际敌方干扰时，各地图建筑／英雄／升本时间应接近。每局自动保存opening-timing-review.json/md，分别记录下单决策、地基出现及完工／单位／科技的实际观察时间。使用data/opening_timing_baseline.json维护参考时点；偏差超过max(20秒,参考时间15%)时优先查资源、人口、工人采集、选址耗时、实际敌方干扰，再考虑地图路径差异。阈值是初始诊断设置，后续按数据校准，不是硬编码开局秒数或验收合格线。

已知异常003530不作正常基准；修后首次经复盘的无干扰开局只能标记candidate，后续多图验证再确认。基准记录版本和来源；版本变化不能直接判失败，缺失时点也必须检查。晚期战斗或非自然终局不自动否定独立有证据的前期开局片段，但不能因此把全局当自然胜负。
