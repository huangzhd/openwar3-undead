## 入口与隔离

`RuleEnvironment(control='primitives')`显式选择外部基础动作模式；默认`control='rule'`保持规则机器人行为。模式在环境创建时确定，单局不能混用`rule_tick`与外部动作。外部模式不创建P1规则Controller，仍复用同一启动、P1白名单观察、KFAI对手、裁判、期限、STOP、进程/epoch检查和清理。

`reset`会启动游戏，因此本轮只在模拟会话中验证接口，没有执行真实reset。返回帧增加`action_context`（schema、公开地图边界、最大决策年龄）及`action_receipts`。`receipts`仍为原生轨迹回执。

动作提交格式如下，`frame`必须来自这个环境本局最近一次返回，句柄必须取自该观察：

```python
env.step({
    'kind': 'primitive',
    'token': frame['token'],
    'action': {
        'schema': 'dayuan-primitive-action-v1',
        'op': 'move',
        'unit': own_unit['handle'],
        'x': 100.0,
        'y': 200.0,
    },
})
```

旧局、跨实例、重复或篡改token在触碰引擎前拒绝。schema不合法也不消费token；合法格式的动作即使执行前检查失败，也消费该决策并返回明确拒绝，不能用旧token重复提交。默认规则模式不接受primitive。

## 严格动作格式

所有动作必须含`schema`和`op`，只接受下表列出的额外字段，多余字段拒绝。句柄为两个正uint32组成的列表，不接受地址、任意订单号或SDK方法名。每step最多一条动作，固定替换当前订单，不提供排队/强制攻击参数。

| op | 额外字段 | 含义 |
|---|---|---|
| wait | 无 | 本次不发送游戏命令；不取消已有订单。 |
| move | unit、x、y | 单位移动。 |
| attack_move | unit、x、y | 攻击移动到地点。 |
| attack | unit、target | 对当前可见P2敌人使用SDK默认目标攻击；不强制攻击友军或中立。 |
| stop | unit | 停止当前订单。 |
| hold | unit | 原地待命。 |

坐标转换为原生float32后记录，拒绝NaN/无穷及超界坐标；边界来自本局已验证地图的公开网格。每个unit必须在决策观察和当前状态中均为己方存活单位，能力详情已知且有Amov；攻击还需Aatk。目标必须在决策观察及执行前均为P1可见、存活的P2单位。隐藏实体不参与能力/目标判断。

执行前重新读取并校验PID/P1/观战身份/epoch/时钟，原观察超过8游戏秒即拒绝（400%下约2墙钟秒，但暂停和调速会改变换算）。同一时钟内的可见性、归属变化也会重新核对；不使用缓存掩码代替最终检查。

`env.preflight(candidates)`最多接受64个候选，返回缓存观察上的`allowed/reason/cached`。这是候选预检查，不是完整合法动作掩码：尚未覆盖所有控制状态、攻击类型/免疫、路径可达或引擎瞬间状态。最终仍可能被SDK仲裁或引擎拒绝。建造、生产、购物、施法、复活、物品操作、高层整队/战略动作本版不支持。

## 记录与效果边界

外部模式新增`primitive-actions.jsonl`，与同目录`trajectory.jsonl`和`interface-contract.json`配套读取：

- `header`：版本、P1/epoch、公开边界、年龄上限、`policy=external_primitives`及限制。
- `request`：完整基础动作、调用方决策观察id。
- `preflight`：执行前观察id/clock、检查结果与有限原因码；同clock重新核验可能比被缓存观察更新。
- `receipt`：基础动作id、接受/拒绝/未知、原生轨迹请求id列表。等待不发命令，accepted为null；预检查拒绝为false；SDK超时99、缺回执和异常为null，异常原文不进入动作日志。
- `next_observation`：之后严格更晚的已记录观察id。结束时没有更晚观察则null，不伪造next状态；始终`effect=unverified`。

接受命令不证明执行效果，后续血量变化也不自动归因给本动作。奖励/终止继续使用原trajectory终局；时间截断无胜负奖励。日志写入/末帧记录失败必须保留错误且继续清理游戏，不能作为合格采集样本。

外部policy和动作版本写入冻结契约，不标为规则教师；`training_actor_approved=false`。原规则轨迹仍为v1，extra/mode等既有缺口未被本次六动作接口自动补齐，不把历史v1转成完整训练标签。原生回执status99现在统一记unknown，符合已有未知回执契约；旧文件不回写。
