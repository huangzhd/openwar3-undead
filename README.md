## 接管控制台（已有工具）

仓库保留此前版本的独立控制台与接管助手。历史安装状态不等于当前运行状态；需要使用时先核对session和attachment，避免重复接管。
窗口显示接管状态、当前意图、战术、英雄/蜘蛛/科技和操作日志；点击“停止接管”交还手动操作，
“继续接管”恢复AI。按钮收到机器人状态确认后才显示成功。停止仅暂停当前局，后续新局仍按自动接管设置执行；

面板每秒刷新，意图/战术来自最近日志，并显示采样时间；旧运行器的意图采样约15游戏秒，不伪称逐帧实时。
控制台只使用现有session命令文件，无鼠标键盘自动操作。重装控制台快捷方式可运行install_console.ps1，无需管理员权限。

需要 Windows、Python 和合法安装的 Warcraft III 1.27a。此仓库只保存本项目源码、测试、数据目录与文档，不包含游戏文件、运行时二进制、第三方上游、虚拟环境、模型或对局 artifacts。历史文档中的 artifacts 路径指开发机本地证据，仓库内不含这些文件。

本项目依赖 [OpenWar3AI](https://war3ai.com/en/)，固定提交 `ffd7dd25a3c2478f457b74bde89d23e605b24243`。将该版本放在 `vendor/OpenWar3AI-ffd7dd25a3c2478f457b74bde89d23e605b24243`，按上游文档配置合法游戏路径、安装运行时并提取游戏数据；`bootstrap.py` 使用该固定目录。首次恢复后先运行 `bot.py check`，确认本地依赖就绪；check不启动游戏。

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-p0.lock
.venv/Scripts/python.exe -B bot.py check
```

## 使用

在本目录 PowerShell 运行：

```powershell
.venv\Scripts\python.exe bot.py check
.venv\Scripts\python.exe bot.py play --speed 400
```

游戏会打开独立窗口；通过接口获取状态、下达语义指令，不模拟鼠标键盘。请勿最小化游戏窗口（本版运行时最小化会导致时钟停滞）。机器人自主操作部队；你可手动点击速率按钮。停止：

```powershell
.venv\Scripts\python.exe bot.py stop
```

停止请求会由运行器处理并关闭本项目记录的游戏进程。检查命令不启动游戏。默认四倍速：短测实际约 3.70 倍；两倍速短测实际约 2.02 倍。启动支持 --speed 25 / 50 / 100 / 200 / 400 / 800。游戏右上方提供「减速｜当前倍率｜加速」，按 1/4、1/2、1、2、4、8 倍逐档切换，两端停止。中间只显示引擎已回读倍率；提交中的设置和失败另行显示。若更快速度导致指令跟不上，可手动降档。比赛与训练预算始终按现实时间计。

展开游戏中的“调试台 0.1.53”可操作“认输”和“重开”：认输结束当前局且不续局；重开先保存并清理旧局，再沿用当前对手、难度和实际倍率开一局。点击后按钮禁用，防止重复提交。自然胜负或异常不会自动续局。正常对战默认不限时，只有显式 `--minutes` / `--until` 才设置截止。

LR发狂不死族启动命令（仅在明确恢复实测并核验无现存对局后执行）：

```powershell
.venv/Scripts/python.exe -B bot.py play --map LR --enemy-race 3 --difficulty 4 --speed 400
```
